# Eme to Dia Promotion 기능명세서

## 구현 목적

`Eme_to_Dia_Promotion` 씬은 월드에 배치된 아이템을 획득하고, 인벤토리에 저장한 뒤, 선택한 아이템을 사용해 플레이어 상태가 즉시 변하는 흐름을 검증하기 위한 과제용 씬입니다.

## 아이템 데이터 구조

아이템의 변하지 않는 기획 데이터는 `DaniTechItemData`가 담당합니다. 이 클래스는 `GameDataBase`를 상속하며, `Assets/Resources/DaniTech/data/dani_items.json`에서 `GameDataManager`가 로드합니다.

아이템 데이터에는 다음 정보가 있습니다.

- 고유 ID: 인벤토리와 월드 아이템이 공유하는 식별자입니다.
- 표시 이름, 타입, 설명, 아이콘 텍스트: UI 표시용 정보입니다.
- Addressables 주소: 월드 아이템 프리팹을 비동기로 생성할 때 사용하는 주소입니다.
- 효과 타입과 수치: HP 회복, 보호막 증가, 스태미나 회복, 이동 속도 증가를 구분합니다.
- 사용 조건: HP가 최대치일 때 회복제 사용 불가, 보호막이 최대치일 때 보호막 아이템 사용 불가 같은 규칙입니다.
- 최대 스택 수와 쿨타임: 인벤토리 수량 제한과 재사용 제한에 사용됩니다.

## 인벤토리 관리 방식

게임 진행 중 변하는 데이터는 `DaniTechInventoryModel`, `DaniTechItemModel`, `DaniTechPlayerModel`이 담당합니다. 이 모델들은 `GameManager`가 소유합니다.

인벤토리는 12칸 고정 슬롯입니다. 아이템 획득 시 같은 아이템이 있으면 `MaxStackCount` 안에서 먼저 합쳐지고, 남은 수량은 빈 슬롯에 들어갑니다. 빈 슬롯이 없으면 획득이 실패하고 로그로 확인할 수 있습니다.

선택 상태는 `SelectedSlotIndex`로 관리합니다. UI 슬롯 클릭 또는 숫자 키로 선택할 수 있고, 선택된 아이템은 HUD와 인벤토리 상세창에 표시됩니다.

정렬은 세 가지 방식입니다.

- 이름 기준 정렬
- 타입 기준 정렬
- 획득 순서 기준 정렬

## 아이템 사용 흐름

1. 플레이어가 월드 아이템을 바라보고 E 키를 누릅니다.
2. `DaniTechPlayerInteraction`이 Raycast로 `IInteractable`을 찾습니다.
3. `DaniTechItemPickup`이 자신의 아이템 ID와 수량을 `DaniTechPromotionManager`에 전달합니다.
4. `DaniTechInventoryModel`이 수량을 슬롯에 저장합니다.
5. Tab 또는 I 키로 인벤토리를 열고 아이템을 선택합니다.
6. 사용 버튼 또는 T 키를 누르면 사용 조건과 쿨타임을 검사합니다.
7. 조건이 맞으면 `DaniTechPlayerModel`에 효과를 적용하고, 아이템 수량을 1 감소시킵니다.
8. HUD와 로그에서 HP, 보호막, 스태미나, 이동 속도 변화가 즉시 확인됩니다.

## 추가 구현 요소

- Addressables 그룹 `DaniTechPromotion`에 아이템 프리팹과 UI/VFX 프리팹 주소를 등록했습니다.
- UI는 런타임에서 `new GameObject()`로 만들지 않고, 에디터 빌더가 만든 프리팹을 씬에 배치합니다.
- 드래그한 인벤토리 슬롯을 Drop 영역에 놓으면 선택 아이템을 1개 버립니다.
- 쿨타임이 남은 아이템은 남은 시간이 슬롯과 상세창에 표시됩니다.
- `D:/3D_Basic_Assets`의 Kitbash3D Brooklyn FBX를 선별 임포트해 다이아 승급 구역 테마 배경으로 사용했습니다.

## 조작

- WASD: 이동
- 마우스: 시점 회전
- E: 월드 아이템 획득
- Tab 또는 I: 인벤토리 열기/닫기
- 숫자 1~9: 슬롯 선택
- T: 선택 아이템 사용
- G: 선택 아이템 버리기
- R: 정렬 방식 순환

## 체크리스트 대응표

### 필수 구현 요소

- [x] 아이템 획득: `DaniTechItemPickup`이 월드 아이템 상호작용을 담당하고, 플레이어가 E 키로 의도적으로 획득합니다.
- [x] 인벤토리 이동: `DaniTechPromotionManager.TryCollectItem`이 획득한 아이템을 `DaniTechInventoryModel.TryAddItem`으로 전달합니다.
- [x] 인벤토리 표시: HUD의 BAG 패널과 Tab/I 인벤토리 창에서 현재 보유 아이템 목록을 확인합니다.
- [x] 아이템 식별: `DaniTechItemData`가 ID, 이름, 타입, 아이콘 텍스트, 설명, Addressables 키, 효과, 사용 조건, 최대 스택, 쿨타임을 가집니다.
- [x] 인벤토리 열기/닫기: Tab/I 또는 Close 버튼으로 열고 닫습니다. 열려 있는 동안 마우스 커서를 표시합니다.
- [x] 아이템 선택: 슬롯 클릭 또는 숫자 1~9 입력으로 선택하고, 선택 슬롯은 배경색과 상세창으로 구분합니다.
- [x] 아이템 사용: Use 버튼 또는 T 키가 선택 아이템의 사용 로직을 실행합니다.
- [x] 상태 변화: HP 회복, 보호막 증가, 스태미나 회복, 이동속도 버프가 `DaniTechPlayerModel`에 반영됩니다.
- [x] 상태 변화 확인: HUD 수치, 상태바, 상세 로그, 쿨타임 텍스트로 사용 전후 변화를 확인합니다.

### 추가 구현 요소

- [x] 설명/툴팁 표시: 조준 중인 월드 아이템은 HUD 툴팁으로, 인벤토리 선택 아이템은 상세창으로 설명을 표시합니다.
- [x] 정렬: Name, Type, Recent 버튼과 R 키 순환 정렬을 제공합니다.
- [x] 슬롯 제한: 인벤토리는 12칸 고정이며, HUD와 인벤토리 제목에 슬롯 수를 표시합니다.
- [x] 드래그 & 드랍: 슬롯을 Use 영역에 끌어 놓으면 아이템을 사용하고, Drop 영역에 끌어 놓으면 선택 아이템을 1개 버리고 월드에 다시 생성합니다.
- [x] 사용 조건: HP 최대치일 때 회복 아이템 사용 불가, 보호막 최대치일 때 보호막 아이템 사용 불가 규칙을 적용합니다.
- [x] 쿨타임: 아이템 사용 후 쿨타임 동안 재사용을 막고, 슬롯과 상세창에 남은 시간을 표시합니다.

### 시연 순서

1. 월드 아이템을 바라보고 E 키로 획득합니다.
2. 좌측 HUD의 BAG 패널에서 아이템이 추가된 것을 확인합니다.
3. Tab/I로 인벤토리를 열고 슬롯, 상세 설명, 스택, 사용 조건, 쿨타임을 확인합니다.
4. 슬롯을 선택한 뒤 Use 버튼 또는 T 키로 사용합니다.
5. HP, 보호막, 스태미나, 이동속도 수치 변화와 로그를 확인합니다.
6. Name/Type/Recent 버튼 또는 R 키로 정렬합니다.
7. 슬롯을 Use 영역으로 드래그해 사용이 실행되는지 확인합니다.
8. 슬롯을 Drop 영역으로 드래그해 아이템 수량 감소와 월드 재생성을 확인합니다.
