# Eme to Dia Promotion 기능명세서

## 1. 프로젝트 기본 정보

- 프로젝트명: 3D_PA_eme_to_dia-
- 개발 기간: 2026.06.22 ~ 2026.06.23
- Git Repository URL: https://github.com/LoOO1224/3D_PA_eme_to_dia-
- 시연 씬: Eme_to_Dia_Promotion

## 2. 핵심 시스템 요약

이 프로젝트의 중심 흐름은 월드에 놓인 아이템을 획득하고, 그 아이템을 인벤토리에 보관한 뒤, 선택한 아이템을 사용해서 플레이어 상태가 바뀌는 구조입니다. 플레이어가 필드 아이템을 바라보고 E 키를 누르면 바로 상태를 바꾸지 않고, 먼저 인벤토리에 들어갈 수 있는지 확인합니다. 가방에 들어간 아이템은 HUD의 BAG 요약과 Tab/I 인벤토리 창에 표시되고, 선택된 아이템만 사용 로직으로 넘어갑니다.

아이템 사용은 단순히 버튼을 누르면 무조건 실행되는 방식이 아닙니다. 선택된 슬롯이 비어 있는지, 아이템 데이터가 존재하는지, 쿨타임이 남아 있는지, HP나 보호막 조건에 걸리지 않는지를 순서대로 검사합니다. 조건을 통과했을 때만 플레이어 상태 모델에 효과를 적용하고, 인벤토리 수량을 1개 줄입니다.

## 3. 아이템 획득 시스템

월드에 배치된 아이템 오브젝트는 `DaniTechItemPickup` 컴포넌트를 가지고 있습니다. 이 컴포넌트는 자신이 어떤 아이템인지 나타내는 `itemId`와 획득 수량인 `amount`만 가지고 있습니다. 실제 이름, 설명, 효과, 쿨타임 같은 정보는 아이템 오브젝트가 직접 들고 있지 않고, `itemId`를 통해 데이터 매니저에서 다시 조회합니다.

플레이어의 상호작용은 `DaniTechPlayerInteraction`이 담당합니다. 카메라 방향으로 Raycast를 쏴서 `IInteractable`을 구현한 대상을 찾고, 아이템을 바라보고 있을 때 HUD에 획득 안내를 표시합니다. E 키를 누르면 아이템 오브젝트가 `DaniTechPromotionManager`로 전달되고, 매니저는 `GameDataManager`에서 해당 아이템의 정적 데이터를 찾은 뒤 `DaniTechInventoryModel.TryAddItem()`으로 가방에 추가를 요청합니다.

가방에 같은 아이템이 이미 있으면 기존 슬롯에 먼저 수량을 더합니다. 단, 아이템마다 `MaxStackCount`가 있어서 한 슬롯의 최대 수량을 넘길 수 없습니다. 남은 수량은 빈 슬롯에 새로 들어가고, 빈 슬롯이 없으면 획득은 실패합니다. 이때 실패한 아이템은 월드에서 사라지지 않으므로, 가방이 가득 찬 상태에서 아이템이 유실되는 상황을 막았습니다.

## 4. 아이템 데이터 구조

아이템 데이터는 변하지 않는 기획 데이터와 플레이 중 변하는 보유 데이터를 분리했습니다. 변하지 않는 정보는 `DaniTechItemData`가 맡습니다. 이 클래스는 `GameDataBase`를 상속받고, `Assets/Resources/DaniTech/data/dani_items.json`에서 로드됩니다. `GameDataManager`는 JSON을 읽은 뒤 아이템 ID를 키로 삼아 딕셔너리에 저장합니다.

`DaniTechItemData`에는 아이템 ID, 표시 이름, 타입, 아이콘 텍스트, 설명, Addressables 주소, 효과 타입, 사용 조건, 최대 스택 수, 효과 수치, 지속 시간, 쿨타임이 들어갑니다. 예를 들어 `diamond_tonic`은 HP 회복 효과를 가지고, `prism_shield`는 보호막을 올리며, `swift_sigil`은 일정 시간 이동 속도 배율을 높입니다. `emerald_core`는 스태미나를 회복하는 아이템으로 구분했습니다.

반대로 인벤토리 안에서 변하는 정보는 `DaniTechItemModel`이 관리합니다. 이 모델은 `itemId`, `amount`, `acquiredSequence`만 저장합니다. 이름이나 설명을 슬롯마다 복사해 두지 않고, 화면에 표시하거나 사용할 때마다 `itemId`로 `GameDataManager`에서 정적 데이터를 다시 가져옵니다. 이렇게 나누면 아이템 설명이나 수치를 바꿔도 인벤토리 저장 구조를 크게 바꿀 필요가 없습니다.

## 5. 인벤토리 시스템

인벤토리의 실제 규칙은 `DaniTechInventoryModel`에 있습니다. 이 모델은 12개의 고정 슬롯을 가지고 있고, 각 슬롯에는 `DaniTechItemModel`이 들어갑니다. 모델은 UI 오브젝트를 직접 알지 않고, 수량 추가, 슬롯 선택, 사용, 버리기, 정렬 같은 데이터 규칙만 처리합니다. 데이터가 바뀌면 `OnInventoryChanged` 이벤트를 발생시키고, HUD와 인벤토리 UI가 이 이벤트를 받아 화면을 갱신합니다.

인벤토리 UI는 `DaniTechInventoryUI`가 관리합니다. Tab 또는 I 키로 열고 닫을 수 있고, 열린 상태에서는 마우스 커서를 보이게 해서 슬롯을 클릭할 수 있습니다. 슬롯에는 아이콘 텍스트, 아이템 이름, 수량, 쿨타임이 표시됩니다. 선택된 슬롯은 배경 색으로 구분하고, 상세 영역에는 타입, 설명, 스택 수, 사용 조건, 효과, 남은 쿨타임을 보여줍니다.

HUD에도 간단한 인벤토리 요약을 넣었습니다. 왼쪽 상단 BAG 영역에는 현재 보유 중인 아이템 개수와 앞쪽 아이템 목록이 표시됩니다. 그래서 인벤토리 창을 열지 않아도 방금 획득한 아이템이 가방에 들어왔는지 바로 확인할 수 있습니다. 정렬은 이름, 타입, 획득 순서 기준으로 제공하고, R 키 또는 정렬 버튼으로 바꿀 수 있습니다.

## 6. 아이템 선택과 사용

아이템 선택은 인벤토리 슬롯 클릭과 숫자키 1~9 입력으로 처리됩니다. 선택된 슬롯 번호는 `DaniTechInventoryModel.SelectedSlotIndex`에 저장됩니다. 선택 상태는 인벤토리 슬롯 색, 선택 아이템 상세 정보, HUD의 `Selected` 텍스트로 확인할 수 있습니다.

아이템 사용은 Use 버튼 또는 T 키로 실행됩니다. 사용 요청이 들어오면 `DaniTechPromotionManager`가 `DaniTechInventoryModel.TryUseSelectedItem()`을 호출합니다. 이 함수는 먼저 선택된 아이템이 있는지 확인하고, `GameDataManager`에서 아이템 데이터를 조회합니다. 그 다음 같은 아이템의 쿨타임이 남았는지 검사하고, `DaniTechPlayerModel.CanUseItem()`으로 HP나 보호막 같은 사용 조건을 확인합니다.

조건을 통과하면 `DaniTechPlayerModel.ApplyItem()`이 호출됩니다. 아이템의 `EffectType`에 따라 HP 회복, 보호막 증가, 스태미나 회복, 이동 속도 버프 중 하나가 적용됩니다. 적용이 끝나면 선택된 아이템 수량을 1개 줄이고, 수량이 0이 된 슬롯은 비웁니다. 쿨타임이 있는 아이템은 현재 시간에 쿨타임 초를 더해서 다음 사용 가능 시간을 저장합니다.

## 7. 상태 변화와 피드백

플레이어 상태는 `DaniTechPlayerModel`이 관리합니다. HP는 최대 HP를 넘지 않도록 회복되고, 보호막은 최대 60을 넘지 않도록 제한됩니다. 스태미나는 최대 스태미나까지만 회복됩니다. 이동 속도 버프는 배율과 지속 시간을 저장하고, 매 프레임 남은 시간을 줄이다가 시간이 끝나면 기본 배율로 돌아갑니다.

상태 변화는 HUD에서 바로 확인할 수 있도록 만들었습니다. HP, Stamina, Shield는 각각 숫자와 게이지 바로 표시됩니다. 이동 속도는 `Speed x배율`과 남은 시간으로 표시됩니다. 아이템을 사용하면 로그 영역에도 결과가 남고, 실패한 경우에는 왜 실패했는지 메시지를 출력합니다. 예를 들어 HP가 이미 가득 찬 상태에서 회복 아이템을 사용하려 하면 회복 조건 때문에 사용되지 않았다는 피드백이 남습니다.

## 8. 추가 구현 요소

- 설명/툴팁 표시: 바라보고 있는 필드 아이템은 HUD 툴팁으로, 인벤토리에서 선택한 아이템은 상세 패널로 설명을 보여줍니다.
- 정렬 기능: 이름, 타입, 획득 순서 기준으로 인벤토리 정렬을 제공합니다.
- 슬롯 제한: 인벤토리는 12칸 고정 슬롯으로 구성되어 있고, 아이템마다 최대 스택 수가 다릅니다.
- 드래그 앤 드롭: 슬롯을 Use 영역에 드롭하면 사용, Drop 영역에 드롭하면 버리기 흐름으로 연결됩니다.
- 사용 조건: HP가 가득 차 있으면 회복 아이템을 막고, 보호막이 최대치면 보호막 아이템을 막습니다.
- 쿨타임: 쿨타임이 남은 아이템은 재사용을 막고, 남은 시간을 슬롯과 상세 영역에 표시합니다.
- Addressables: 월드 아이템 프리팹은 Addressables 주소를 통해 생성되며, 로드 실패 시에도 기본 폴백 아이템이 나오도록 했습니다.

## 9. 조작 방법

- WASD: 이동
- 마우스 우클릭 드래그: 시점 회전
- 마우스 휠 또는 V: 카메라 거리 조절
- E: 필드 아이템 획득
- Tab 또는 I: 인벤토리 열기/닫기
- 숫자 1~9: 인벤토리 슬롯 선택
- T: 선택 아이템 사용
- G: 선택 아이템 버리기
- R: 정렬 방식 전환

## 10. 시연 영상에 포함할 흐름

1. `Eme_to_Dia_Promotion` 씬을 실행하고 HUD, 캐릭터, 필드 아이템, 배경을 보여줍니다.
2. 마우스와 휠로 카메라를 조절해 1인칭/3인칭 시점과 캐릭터 표시를 확인합니다.
3. 필드 아이템을 바라보고 E 키로 획득합니다.
4. HUD BAG 영역에서 아이템이 추가된 것을 확인합니다.
5. Tab/I로 인벤토리를 열고 슬롯, 수량, 상세 설명을 보여줍니다.
6. 아이템을 선택하고 Use 버튼 또는 T 키로 사용합니다.
7. HP, Shield, Stamina, Speed 중 하나가 바뀌는 장면을 HUD 숫자와 게이지로 확인합니다.
8. 사용 후 아이템 수량이 감소하거나 슬롯이 비는 장면을 보여줍니다.
9. 정렬, 드래그 사용, 드래그 버리기, 쿨타임 표시 중 구현된 추가 기능을 짧게 보여줍니다.

## 11. 체크리스트 대응표

- 아이템 획득: `DaniTechItemPickup`과 `DaniTechPlayerInteraction`을 통해 월드 아이템을 E 키로 획득합니다.
- 인벤토리 이동: `DaniTechPromotionManager.TryCollectItem()`이 획득 아이템을 `DaniTechInventoryModel`에 추가합니다.
- 인벤토리 표시: HUD BAG 패널과 Tab/I 인벤토리 창에서 현재 보유 아이템을 표시합니다.
- 아이템 식별: `DaniTechItemData`가 ID, 이름, 아이콘, 설명, 타입, 효과, 조건을 가집니다.
- 인벤토리 열기/닫기: Tab/I와 Close 버튼으로 열고 닫을 수 있습니다.
- 아이템 선택: 슬롯 클릭 또는 숫자키로 선택하며, 선택 슬롯은 색상과 상세 정보로 구분됩니다.
- 아이템 사용: Use 버튼, T 키, Use 드롭 영역으로 선택 아이템을 사용합니다.
- 상태 변화: HP 회복, 보호막 증가, 스태미나 회복, 이동 속도 버프가 플레이어 모델에 반영됩니다.
- 변화 확인: HUD 숫자, 게이지, 선택 아이템 텍스트, 로그 메시지로 사용 전후 차이를 확인합니다.
